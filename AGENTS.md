# Repository agent instructions

Before proposing, changing, reviewing, or running any vision pipeline, read
`docs/vision-system.md` and then `docs/PIPELINE.md`.

- `docs/vision-system.md` is the canonical owner-approved product and operating intent.
- `docs/PIPELINE.md` is the current implementation/runbook.

Do not mistake a planned capability for a shipped one. Any new vision decision must
follow the maintenance protocol in `docs/vision-system.md`, including its dated decision
log and implementation-status update.
